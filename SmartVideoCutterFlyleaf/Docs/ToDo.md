- Для WPF использовать сторонние элементы из NuGet:
  - Flyleaf.WPF, Flyleaf.FFmpeg:
    Современная, невероятно быстрая библиотека для WPF на базе FFmpeg. 
    Она создана специально для задач компьютерного зрения и плавной отрисовки. 
    Она позволяет перехватывать кадры до того, как они попадут на экран, 
    обрабатывать их в YOLO и отдавать плееру дальше.
    Если вам нужна максимальная производительность, 
    минимальные задержки и работа напрямую с видеокартами Nvidia/AMD — используйте Flyleaf. 
    Это лучшее решение для задач ИИ и компьютерного зрения на WPF на сегодняшний день.
  - LibVLCSharp.WPF, VideoLAN.LibVLC.Windows:
    Официальная библиотека от VLC. 
    У нее есть специальный режим VideoCallbacks, 
    который позволяет получать сырые пиксели каждого кадра в массив (или WriteableBitmap), 
    выполнять детекцию YOLO и выводить на экран.
    Если проект должен быть максимально стабильным,
    поддерживать любые форматы файлов "из коробки" и не требовать сложной настройки декодеров —
    используйте LibVLCSharp.
